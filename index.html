ABOUT MESHCHAT

How it works

MeshChat is an offline-first messenger. Direct one-to-one messaging uses verified peers and the existing encrypted channel over supported nearby transports. Wi-Fi Direct is implemented in source but not yet verified on phones. No central message server is used. Messages are stored locally and encrypted in transit between paired devices.

Multi-hop chat delivery still lacks destination-key management; group messaging, file transfer, and voice calls need a Wi-Fi Direct link and have not been tested on phones yet.
