ABOUT MESHCHAT

How it works

MeshChat is an offline-first messenger concept. Today it supports direct one-to-one chat between two phones in Bluetooth range. Multi-hop mesh relay is planned but not built yet. No central message server is used. Messages are stored locally and encrypted while they travel between paired phones.

This initial build does not claim that all transport, relay, group, or file-transfer features are complete.
